# Reforma Tributária do Consumo

Os três projetos abaixo foram publicados pela Receita Federal do Brasil. Cada submódulo aponta para um commit dos projetos oficiais. Os arquivos de código e os avisos da licença MIT ficam em cada projeto.

| Projeto | Para que serve | Código oficial |
| --- | --- | --- |
| Regime Regular | Calcula CBS, IBS e Imposto Seletivo. | [GitHub](https://github.com/ReceitaFederal/calculadora-rtc-regime-regular) · [Baixar ZIP](https://github.com/ReceitaFederal/calculadora-rtc-regime-regular/archive/f1eebd7ce3157423b1a6aaca7dc1d6c3395452c4.zip) |
| Simples Nacional | Calcula CBS e IBS nas operações do Simples Nacional. | [GitHub](https://github.com/ReceitaFederal/calculadora-rtc-simples-nacional) · [Baixar ZIP](https://github.com/ReceitaFederal/calculadora-rtc-simples-nacional/archive/a926d5a76095ac0295a6612a9a54db7ffead2396.zip) |
| Gerador de DANFSe | Gera o PDF auxiliar a partir do XML de uma NFS-e. | [GitHub](https://github.com/ReceitaFederal/calculadora-rtc-gerador-danfse) · [Baixar ZIP](https://github.com/ReceitaFederal/calculadora-rtc-gerador-danfse/archive/8d79e6b2f7fad6375340afcb51c85ed370c64a14.zip) |

Para baixar os três projetos numa cópia local do NestorPro, use `git submodule update --init -- reforma-tributaria`. Em cada pasta, consulte o `README.md` e o arquivo `LICENSE` oficiais.
