# Componentes e distribuição

O NestorPro DIRETO utiliza componentes de terceiros. Esta página de apresentação não inclui código-fonte, executáveis nem instaladores desses componentes.

| Componente | Uso | Fonte |
|---|---|---|
| Interception | Captura de teclado e mouse | https://github.com/oblitum/Interception |
| ViGEmBus | Dispositivo de controle virtual | https://github.com/nefarius/ViGEmBus |
| Nefarius.ViGEm.Client | Comunicação com o barramento virtual | https://github.com/nefarius/ViGEm.NET |
| .NET | Execução e interface Windows | https://github.com/dotnet/runtime |

## Pendências antes de distribuir

O projeto Interception declara licenciamento distinto para uso não comercial e comercial. A licença comercial correspondente ainda precisa ser confirmada para este produto. Não se deve apresentar a revisão como concluída.

O repositório oficial ViGEmBus está arquivado. Isso precisa ser considerado na compatibilidade e no suporte da distribuição.

A publicação de documentação não concede licença sobre o aplicativo ou sobre componentes de terceiros. Cada componente mantém os seus termos e avisos.
