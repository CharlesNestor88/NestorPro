# Requisitos e alcance de compatibilidade

| Item | Situação |
|---|---|
| Arquitetura | O executável atual é Windows x64 |
| Runtime | A compilação distribuída para testes é autocontida em .NET 10 |
| Captura | Interception instalado e carregado após reinicialização |
| Saída virtual | ViGEmBus disponível |
| Dispositivos | Teclado e mouse; compatibilidade deve ser testada por modelo/configuração |
| Jogo | Fluxos desenvolvidos com foco no Warzone; versões novas precisam de reteste |
| Administração | Pode ser necessária para instalar drivers |
| Instalação pública | Em preparação |

## O que não está certificado

Não há certificação universal para todas as edições do Windows, todos os mouses, Windows Server, máquinas virtuais, sessões RDP ou jogos. Abertura do painel em uma máquina não comprova a captura física nem a resposta dentro do jogo.

Não há requisito de hardware mínimo de FPS publicado: ele depende também do jogo e não foi estabelecido por ensaio reproduzível do produto.

Os drivers têm requisitos e manutenção próprios. Utilize as fontes oficiais indicadas em Componentes e não desative proteções do Windows para contornar incompatibilidades.
