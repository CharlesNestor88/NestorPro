# Créditos e componentes de terceiros

## Base KeyboardToGamepad

O NestorPro deriva de KeyboardToGamepad, de zzz1999 e colaboradores:
https://github.com/zzz1999/KeyboardToGamepad

A licença MIT e o aviso de copyright originais foram preservados no arquivo LICENSE, junto à atribuição das alterações do NestorPro. A publicação da base não representa endosso deste projeto pelos autores originais.

## Dependências

| Componente | Uso | Origem |
|---|---|---|
| Nefarius.ViGEm.Client 1.21.256 | Cliente .NET para o controle virtual | https://github.com/nefarius/ViGEm.NET |
| Spectre.Console 0.49.1 | Interface do modo console legado | https://github.com/spectreconsole/spectre.console |
| Interception | Biblioteca nativa e driver de captura | https://github.com/oblitum/Interception |
| ViGEmBus | Driver de controle virtual | https://github.com/nefarius/ViGEmBus |
| .NET / Windows Forms | Runtime e interface | https://github.com/dotnet/runtime |

As dependências NuGet são restauradas de seus provedores. Os binários e instaladores Interception/ViGEmBus não estão incluídos neste repositório.

O Interception declara licenciamento distinto para uso não comercial e comercial. A licença MIT deste código não altera os termos do Interception nem concede direitos sobre seus drivers e instaladores. Confira os termos do componente antes de redistribuir uma compilação ou utilizá-la comercialmente.

O ViGEmBus está arquivado em sua origem; a compatibilidade futura do driver não é garantida pelo NestorPro.

Marcas e nomes de terceiros pertencem a seus titulares. NestorPro é um projeto independente.
