# Biblioteca nativa externa

A DLL x64 e os instaladores não estão versionados.

Use o script scripts/Get-Interception.ps1 na raiz do repositório, após revisar os termos do Interception, ou obtenha os arquivos em https://github.com/oblitum/Interception/releases/tag/v1.0.1.

A biblioteca x64 deve ficar nesta pasta como interception.dll para ser incluída na compilação. A instalação do driver exige uma etapa separada e pode exigir administrador e reinicialização.

O NestorPro também precisa do ViGEmBus para criar o controle virtual. Nenhum driver é instalado automaticamente ao compilar.
